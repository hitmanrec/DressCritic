# Текущее состояние и очередь

Версия кода: **0.12.1**. Оценка модели **намеренно заблокирована** кодом
`fixed-views-runtime-review-required`, даже если модель настроена. Это проверочная
ветка рендера в default branch, не готовая конечная версия мода.

## Подтверждено

- Плагин работает в Dressmaker 0.7.0 / Unity 6000.3.4f1 / URP под Linux/Proton.
- Структура активных/сохранённых платьев, выбранный заказ и unlocked membership
  доступны read-only с указанными в RUNTIME ограничениями.
- Точная связь сохранённой записи с отображаемым платьем найдена и проверена.
- Локальный Instruct VLM реально возвращал четыре оценки. Первый полный цикл:
  17.3 с, среднее 6.25. Это работавший **одиночный** вид, не калиброванный evaluator.
- Четыре стандартных URP render request работают. Исправленное кадрирование
  проверено на зелёном и украшенном платьях; геометрия стабильна при повороте.
- Игровой свет меняется относительно манекена: фиксированные камеры сами по
  себе не обеспечивают одинаковое освещение.
- Скриншоты после изолированного рендера показывают оставшиеся дефекты:
  перед темнее спины и отсутствует часть аксессуаров.

## Единственное требуемое сейчас действие в игре

Закрыть игру, `git pull --ff-only`, `bash install.sh`. Один захват того же
украшенного платья через Жюри → Оценить платье; `bash pull-exports.sh`.
Нужен полный пакет, включая accessory-render.json, fixed-views.json,
targeted-api.json и PNG. Повтор поворота сейчас не нужен: сначала исследуются
пропущенный декор и источники света. Модель/конфиг менять не требуется.
Новый in-game пакет v0.12.1 пока не разобран и его исправность не подтверждена.

## Проверки и практические границы

`dotnet run --project tests/Introspection.Tests.csproj` проверяет production core,
fixtures и инъецированный HTTP. `python3 tests/test_capture_importer.py` проверяет
импорт; `python3 tools/review_capture.py PATH` — артефакты конкретного пакета.
Ядро собиралось для net472; полный native plugin нельзя собрать здесь без
авторизованных game DLL. Roslyn syntax check не проверяет типы Unity API.
Случаи FontStyle/TextRenderingModule и LoadImage/netstandard это уже подтвердили.
